# Learning and Adaptation

## Distinction

**Automation** performs a task.

**Intelligence** learns from performing the task.

**Living Intelligence** changes the system that performs the task.

## Learning Loop

Experience → Feedback → Learning → Adaptation → New Experience

## Organizational Dimension

Learning can occur at multiple levels:

1. Individual
2. Team
3. Organization
4. Network
5. Collective / planetary
