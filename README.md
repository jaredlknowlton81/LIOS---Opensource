## Repository Structure

This repository currently holds a large and growing set of root-level markdown files, each documenting a specific framework, architecture, or concept within Living Intelligence, alongside a `src/lios/` folder for LIOS code, a `docs/` folder, and a `tests/` folder. `CLAUDE.md` and `AGENTS.md` are included so AI agents can work directly in the repository.

This flat structure reflects the project's current stage as an early exploration and living draft. A cleaner structure — organizing content into folders such as `structures/`, `knowledge/`, `examples/`, and `skills/` — is a direction being worked toward as the practice matures, not yet the current state of the repository.

> Note: the "intentionally lightweight" framing elsewhere in this document describes the project's philosophy, not its current file count, which has grown substantially as frameworks have been explored in parallel.
