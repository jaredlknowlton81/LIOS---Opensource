# Capability Acquisition Framework

## Primary Question

> Does the acquired capability merely perform work, or does it increase the organization's ability to learn, adapt, and act intelligently over time?

## Acquisition Dimensions

- Experience
- Capture
- Persistent Context
- Sensemaking
- Knowledge
- Action
- Feedback
- Learning
- Adaptation
- Emergence

## Evaluation Principle

A capability should be evaluated not only by what it can do now, but by whether it increases the system's capacity to become more capable over time.
