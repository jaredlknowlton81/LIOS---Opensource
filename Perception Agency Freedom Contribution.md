# Perception → Agency → Freedom → Contribution → Generativity

This is the deepest purpose sequence in the architecture.

---

# Perception

See more.

See more accurately.

See more broadly.

See patterns that were previously invisible.

---

# Agency

Become capable of:

- choosing
- acting
- learning
- changing course

---

# Freedom

Gain meaningful ability to:

- choose direction
- refuse
- change
- leave
- reconsider
- create

---

# Contribution

Use freedom to create value beyond the self.

---

# Generativity

Create conditions in which others can also:

- perceive
- choose
- become free
- contribute

---

PERCEPTION

  FREEDOM
