# Wander: Dream Journal — Visual Reference

## Reference

**Wander: Dream Journal** by Ryan Bush.

Its cover presents a modular, interconnected world composed of distinct environments, including spaces resembling:

- bedroom
- classical hall
- forest
- pool
- car/garage
- theater

These environments connect like pieces of a larger landscape.

---

# Why It Matters

The image provides a powerful metaphor for:

[[Build Your World]]

and

[[Living Intelligence Architecture]]

---

# The Metaphor

A world does not need to be one giant environment that performs every function.

Instead:

> **A world can be an ecology of environments.**

Each environment can provide:

- a different experience
- a different practice
- a different relationship
- a different perspective
- a different possibility

---

# The Room Metaphor

Imagine:

**Listening Room**

for receiving reality.

**Observatory**

for seeing patterns.

**Knowledge Garden**

for cultivating ideas.

**Scenario Room**

for imagining futures.

**Practice Room**

for developing capability.

**Community Room**

for shared action.

**Compass Room**

for deciding direction.

---

# Larger Insight

The intelligence does not exist only inside each room.

It emerges from:

**The relationships between the rooms.**

This is a core metaphor for Living Intelligence.
