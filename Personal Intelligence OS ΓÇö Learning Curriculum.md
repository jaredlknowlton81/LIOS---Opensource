The curriculum is not the architecture.

The architecture describes the capabilities the Personal Intelligence OS requires.

The curriculum describes the knowledge and skills we need to learn to understand, design, prototype, and eventually build those capabilities.

Brilliant Learning Map

Brilliant can be treated as one potential learning substrate, rather than as the architecture itself.

The question becomes:

Which Brilliant concepts teach the primitives required by each architectural capability?

|   |   |
|---|---|
|Brilliant / Learning Area|Primary Capability Supported|
|Computer Science|Representation, Search, Execution|
|Algorithms|Search, Planning, Optimization|
|Data Structures|Representation, Context|
|Logic|Reasoning, Decomposition|
|Probability & Statistics|Evaluation, Uncertainty|
|Programming|Execution|
|Neural Networks|Modeling, Learning|
|Machine Learning|Prediction, Adaptation|

The mapping should remain open: a course is valuable insofar as it teaches a capability required by the architecture.

  

Curriculum Objective

The objective is not:

Learn AI.

The objective is:

Learn the computational, mathematical, AI, and systems primitives required to understand and build the Personal Intelligence OS.

The Relationship

The two documents should connect like this:

                 ARCHITECTURE

                      │

          What must the system do?

                      │

                      ↓

             REQUIRED CAPABILITIES

                      │

                      ↓

                  CURRICULUM

                      │

          What must we learn?

                      │

                      ↓

                 APPLICATION

                      │

          What can we actually build?

                      │

                      ↓

                  EXPERIENCE

                      │

                      ↓

                  FEEDBACK

                      │

                      ↓

                 ARCHITECTURE

This creates a learning/build loop:

Architecture → Capability → Learning → Building → Experience → Feedback → Architecture

That separation should make it much easier to distinguish what the Personal Intelligence OS is from how we learn to construct it.
