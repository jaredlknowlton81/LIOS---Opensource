# Learning & Adaptation Gate

## Gate 1 — Experience

- [ ] Does the capability encounter real-world activity?
- [ ] Does it generate new observations or experience?
- [ ] Can experiences be associated with the entities and relationships involved?

## Gate 2 — Capture

- [ ] Can important experiences be captured?
- [ ] Can tacit knowledge become explicit?
- [ ] Is context preserved rather than stripped away?

## Gate 3 — Persistent Context

- [ ] Is experience retained over time?
- [ ] Can the system remember prior interactions?
- [ ] Can relationships and history be reconstructed?
- [ ] Can new experience be connected to previous experience?

## Gate 4 — Sensemaking

- [ ] Can the capability identify patterns?
- [ ] Can it distinguish signal from noise?
- [ ] Can it generate hypotheses?
- [ ] Can humans and AI contribute complementary forms of sensemaking?

## Gate 5 — Knowledge

- [ ] Does learning become reusable knowledge?
- [ ] Can knowledge be transferred across people, teams, and systems?
- [ ] Does the organization become less dependent on individual memory?

## Gate 6 — Action

- [ ] Does intelligence change decisions?
- [ ] Does it change behavior?
- [ ] Can insights reach the point where action occurs?

## Gate 7 — Feedback

- [ ] Are outcomes observed?
- [ ] Are successful and unsuccessful actions recorded?
- [ ] Does the system compare expected outcomes with actual outcomes?

## Gate 8 — Learning

- [ ] Does feedback modify future decisions?
- [ ] Can people, models, processes, or policies improve?
- [ ] Does the capability become more useful through accumulated experience?

## Gate 9 — Adaptation

- [ ] Can the system change when conditions change?
- [ ] Can organizational practices evolve?
- [ ] Can roles and relationships change?
- [ ] Can the capability reveal that the original requirement was wrong?

## Gate 10 — Emergence

- [ ] Does the capability create intelligence that did not exist in the individual components?
- [ ] Does information flow across organizational boundaries?
- [ ] Does the network become more capable as more participants contribute?
- [ ] Is there evidence of collective intelligence rather than merely aggregated individual intelligence?

## Decision

**Tool → Capability → Learning System → Living Intelligence**
