# Intelligence Loop

## Core Loop

**Experience → Capture → Intelligence → Knowledge → Action → Feedback**

The expanded loop adds persistent context, learning, adaptation, and emergence.

## Questions

- What experience is being generated?
- What is captured?
- What context persists?
- How is experience interpreted?
- What knowledge is created?
- How does knowledge change action?
- What feedback returns to the system?
- What changes because of learning?
